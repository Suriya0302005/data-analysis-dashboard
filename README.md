# students-performance-analysis(interactive dashboard creation using power bi)
## project objective 
The Students Performance Analysis Dashboard is to analyze, monitor, and visualize student academic data to improve decision-making, identify performance trends, and enhance overall educational outcomes.

 

 -<a href="https://github.com/Suriya0302005/data-analysis-dashboard/blob/main/Screenshot%20.project%20dashboard.jpg">screenshot

 ## questions (KPIs)
* How many students are there?
* What is the overall average mark?
* What is the highest mark scored?
* What is the lowest mark scored?
* What is the pass percentage?
* Which student is the top performer?
* Which subject has the highest average marks?
* Which subject has the lowest average marks?
* Which department performs the best?
* How does attendance affect student performance?
* How many students are above the average mark?
* How many students are at risk of failing?
